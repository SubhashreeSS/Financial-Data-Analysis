📊 Project Overview
This project analyzes a finance dataset and presents key financial metrics through an Excel dashboard. It focuses on revenue performance, loan approvals and rejections, recovery trends, regional NPA comparisons, customer distribution, and loan amounts by approval status.

The analysis covers January 2022 to December 2024 and is based on a dataset described in the project report as containing 2,000 transactions, 500 customers, and 10 branches. All monetary values are expressed in ₹ Lakhs.
🎯 Project Objectives
- Compare actual revenue with revenue targets.
- Track monthly and yearly revenue performance.
- Summarize loan approvals and rejections.
- Review recovery and Non-Performing Asset (NPA) trends.
- Compare customer counts across branches and NPA across regions.
- Present key performance indicators (KPIs) in a visual dashboard.
- Identify data-quality issues and opportunities for further analysis.

📌 Dashboard Highlights
The dashboard includes:
- KPI cards: Total actual revenue, total approved, total rejected, and average recovery.
- Monthly revenue trend: Actual revenue and target revenue across the reporting period.
- Actual vs. target revenue: Monthly comparison for 2024.
- Branch-level customer distribution: Customer counts across branches.
- Recovery trend: Month-by-month recovery metric.
- Region-wise NPA comparison: Regional comparison of NPA values.
- Loan amount by approval status: Loan amounts split by approval status and loan category.

🔍 Key Findings
Based on the accompanying project analysis:
- Actual revenue was ₹21,947 lakhs against a target of ₹22,458 lakhs, achieving approximately 97.7% of the target.
- Revenue targets were met in 16 of 36 months.
- The reported average recovery was 86.2%.
- The reported average NPA was 7.4%.
- The project analysis identified credit quality, loan defaults, inconsistent category labels, missing values, and region/state mismatches as areas requiring attention.
These figures are taken from the project’s accompanying insights report. The dashboard’s KPI cards use a monthly KPI source for some values, while transaction-level counts may differ.

🧹 Data Quality Checks
The project report identified these data-quality considerations:
- Inconsistent spellings and capitalization in approval status and gender fields.
- Missing loan amounts and payment statuses in transaction records.
- Missing customer credit scores and income values.
- Region and state values that do not always agree between transaction and branch data.
These issues should be considered when interpreting results.

⚠️ Dashboard Validation Note
Before using this dashboard for business decisions, validate the aggregation method for percentage metrics. The project review noted that the Recovery % trend and Region-wise NPA % chart appeared to use Sum rather than Average in the Pivot Tables. For percentage metrics, verify the correct calculation and use the appropriate aggregation.

Also label KPI sources clearly when monthly KPI-sheet totals and transaction-level counts differ.
💡 Recommendations
- Monitor revenue target gaps, especially months where actual revenue falls short.
- Review collections and credit-risk indicators to identify areas needing attention.
- Compare regional and branch-level performance before prioritizing interventions.
- Standardize categorical fields and address missing values at the data source.
- Validate Pivot Table calculations and clearly label the source of each KPI.
